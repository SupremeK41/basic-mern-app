# Basic MERN App

An AI-assisted learning experiment using MongoDB, Express, React and Node.js to explore REST create, read, update and delete operations.

## Project organisation

- `backend/`: Express/Node application.
- `frontend/`: React interface.
- Root `package.json`: development/build/start scripts.

Run `npm install` at the root and inspect the scripts in `package.json`. Local environment variables and a MongoDB connection must be configured before running the application. Credentials are not included in this README.
